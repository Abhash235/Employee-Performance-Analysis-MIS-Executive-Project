# Employee Performance Analysis – MIS Executive Project

## 📌 Project Overview

This project is an **Employee Performance Analysis and MIS Reporting project** created using **Microsoft Excel**.

The main objective of this project is to analyze employee performance, attendance, targets, productivity, and other key performance indicators using Excel. The project demonstrates practical Excel skills commonly used by an **MIS Executive, MIS Analyst, or Data Analyst**.

## 🎯 Objectives

- Analyze employee performance and productivity.
- Track employee targets and achievements.
- Identify high and low-performing employees.
- Create summary reports for management.
- Build interactive and easy-to-understand dashboards.
- Use Excel to convert raw employee data into meaningful business insights.

## 🔄 Project Workflow

1. Collect and import employee data.
2. Clean and format the raw data.
3. Apply Excel formulas and calculations.
4. Create performance-related metrics.
5. Analyze the data using Pivot Tables.
6. Create charts and visualizations.
7. Build an interactive MIS dashboard.
8. Generate insights for management decision-making.
